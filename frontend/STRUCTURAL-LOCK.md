# STRUCTURAL-LOCK.md

## Stack
React + Vite, CSS propio, fetch a las APIs existentes y hosting Amplify.

## Decisions

1. Interfaz en español con shell lateral, módulos por rol y sesión solo en memoria.
2. Tema claro crema con rosa, celeste y menta, según el usuario; no usar la landing oscura inferida por discovery.
3. Firma visual welcome-notebook con mascotas originales CSS y acción a asistencia.
4. Skeletons in situ en todos los listados y tarjetas, con aria-busy y reduced-motion.
5. Ningún valor de negocio inventado; los errores de API no se sustituyen por métricas ficticias.
6. Misma autoridad del backend para permisos y tenant; jamás aceptar claves de acceso en el bundle.

## FREEZE
Una sola metáfora: papelería kawaii para trabajo diario. No agregar componentes de marketing ni testimonios.
